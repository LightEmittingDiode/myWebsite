# LightEmittingDiode 프로젝트 포트폴리오

MoveAWheel 관련 MVW 프로젝트 9개를 3×3 그리드로 소개하는 정적 웹사이트입니다. 노란색을 포인트 컬러로 사용했습니다.

- 공개 웹사이트 4개: 운영 사이트와 GitHub 저장소로 연결
- 비공개 프로젝트 5개: 요약을 공개하고, 저장소 링크에는 접근 권한이 필요함을 표시

## 로컬에서 보기

별도 빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다. 로컬 서버로 확인하려면 저장소 루트에서 다음 명령을 실행하세요.

```bash
python -m http.server 8000
```

`http://localhost:8000`으로 접속합니다.

## 배포

GitHub Pages에서 `main` 브랜치의 저장소 루트를 게시합니다. 배포 주소는 [LightEmittingDiode 프로젝트 포트폴리오](https://lightemittingdiode.github.io/myWebsite/)입니다.

공개 페이지에는 비공개 프로젝트의 이름과 짧은 설명이 표시됩니다. 비공개 저장소의 코드나 파일은 이 저장소에 포함되지 않습니다.
